API Reference

Weather on a living globe

A simple REST API that returns current conditions and a 15-day forecast for any city in the world. No authentication required.

Public No auth Metric units 20 req/s Cached 2h
Endpoint
GET /weather/{city_name}

Returns live weather and a 15-day forecast for the given location.

Rate limit: 20 requests/second Cached per city for 2 hours

Parameter Type Description
city_name string City or place name. Accepts most global locations (e.g. London, Preutesti, Dolhasca).
Response — top level
FieldTypeDescription

longitudenumberLongitude of the location.

currentConditionsobjectLive weather at time of request. See below.
daysarray15-day forecast array. Each entry follows the day object schema.
stationsobjectWeather stations used as data sources, keyed by station ID.
queryCostnumberAlways 1.

days object (forecast)

Each entry in days includes all fields from currentConditions plus the following:

FieldTypeDescription
datetimestringDate in YYYY-MM-DD format.
tempmaxnumberDaily high temperature in °C.
tempminnumberDaily low temperature in °C.
feelslikemaxnumberDaily high feels-like in °C.
feelslikeminnumberDaily low feels-like in °C.
precipcovernumberPercentage of the day with precipitation.
severerisknumberRisk of severe weather (0–100).
descriptionstringPlain-language summary of the day's weather.
Error codes
200 Success. Returns full weather JSON.
400 Invalid location name.
502 Failed to reach the upstream weather service.
503 Upstream weather service unavailable.
500 Internal server error — malformed upstream response.
Responses are cached per location for 2 hours. Repeated requests for the same city within that window return the cached result instantly.
